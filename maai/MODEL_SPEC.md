# MAAi 3Dモデル 受け入れ仕様（Codex向け）

このゲームは敵ファイターをコード内の3Dスケルトン（メートル単位・
文献の実測値でポーズ駆動）で描画している。外部3Dモデルは
**このスケルトンでボーンを駆動する**形で組み込む。
つまり必要なのは「リグ付きの静的モデル」であり、アニメーションは不要。

## 必須要件

1. **形式**: glTF 2.0 バイナリ（.glb）1ファイル。テクスチャ埋め込み。
2. **単位**: メートル。身長1.83m（アラタ基準。体格差はコード側で拡縮）。
3. **向き**: Y-up、+Z が正面（glTF標準）。原点は両足の中間・床の高さ。
4. **ポーズ**: T-pose または A-pose（バインドポーズ）。構えはコードが作る。
5. **リグ**: ヒューマノイド。ボーン名は次のいずれかの規約に統一:
   - Mixamo系: `mixamorig:Hips, Spine, Spine1, Spine2, Neck, Head,
     LeftShoulder, LeftArm, LeftForeArm, LeftHand,（Right同様）
     LeftUpLeg, LeftLeg, LeftFoot, LeftToeBase,（Right同様）`
   - または VRM / UniVRM のヒューマノイド名
   （どちらでもよいが、**全ボーン名の一覧を添付**すること）
6. **ポリゴン数**: 30,000三角形以下（スマホWebGL・60fps目標）。
7. **テクスチャ**: 2048px以下、合計3枚以内。PBRでなくてよい
   （ゲームはセルルック。ベースカラー＋シンプルな陰影で十分）。
8. **サイズ**: .glb 1ファイル 8MB以下
   （単一HTML配布のため base64 埋め込みする。16MB上限の半分まで）。
9. **グローブ**: 4オンスMMAオープンフィンガー。手ボーンの子として
   メッシュを分けておく（拳の回内をコードで回すため）。
10. **顔**: 表情モーフ（BlendShape）があれば使う。最低限:
    `blink`（まばたき）, `mouthOpen`（呼気）, `pain`（被弾）。
    名前一覧を添付。無くても組み込みは可能。

## あると良いもの（任意）

- 3体分の差分（アラタ/ゴウ/レン）: 同一リグ・同一ボーン名で
  メッシュとテクスチャだけ差し替え。体格差はコード側で対応可能なので
  1体でも成立する。
- 汗・ダメージ用の追加テクスチャ（頬の腫れなど）。

## 組み込み側（こちら）の予定

- three.js（cdnjs配信のUMDビルド）で WebGL レイヤーを追加し、
  既存の Canvas 2D エフェクト（集中線・汗・墨の一閃）を上に重ねる。
- ボーンはコードの骨格（腰→体幹→肩→腕の運動連鎖、実測の肘角
  60°→112.9°等）で毎フレーム直接駆動する。焼き込みクリップは使わない。
  これは主観時間で進行を連続制御するため（クリップだと補間が利かない）。
- 受け取り後、まず1体をゲーム内の全12状況で検証してから差し替える。

## 検証チェックリスト（受領時にこちらで実施）

- [ ] glTF Validator を通る
- [ ] ボーン名が仕様どおり
- [ ] スケール1.0で身長1.83m
- [ ] 肘・膝を実測角度（112.9°等）に曲げて破綻しない
    （ウェイト塗りの確認。特に肩まわり）
- [ ] iPhone Safari で 60fps
