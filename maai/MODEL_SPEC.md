# MAAi 3Dモデル 受け入れ仕様（Codex向け）

このゲームは敵ファイターをコード内の3Dスケルトンで描画している。
組み込みは**アニメーションクリップをベース**に、コードの手続き層
（頭の追従・ガード反応・選手ごとの姿勢差）を上に重ねる方式にする。

## アニメーション（重要・方針変更）

フリーのモーキャプ（**Mixamo のボクシングクリップ推奨**。ゲーム組み込みは
ライセンス上可）をベースにする。手続きアニメでは人間の重み・揺れ・
フォロースルーに届かないため。

必要クリップ（この名前でエクスポート）:
- `idle_guard`（構えループ）, `jab`, `cross`, `hook_lead`, `uppercut_rear`
- `block`, `slip_l`, `slip_r`, `hit_head`, `hit_body`, `ko`
- あれば `kick_low`, `knee`, `sprawl`, `walk_fwd`, `walk_back`
条件:
- **in-place**（ルートモーションなし。移動はコードが制御する）
- 30fps、各クリップの**インパクトのフレーム番号を一覧で添付**
  （ゲームはクリップを主観時間で伸縮再生し、インパクトフレームを
  拍に合わせて着弾させる。この番号が無いと同期できない）
- 全クリップ同一リグ（Mixamoリグのままでよい）

## 必須要件

1. **形式**: glTF 2.0 バイナリ（.glb）1ファイル。テクスチャ埋め込み。
2. **単位**: メートル。身長1.83m（アラタ基準。体格差はコード側で拡縮）。
3. **向き**: Y-up、+Z が正面（glTF標準）。原点は両足の中間・床の高さ。
4. **ポーズ**: バインドはT-pose。ゲーム内の構え・動きは上記クリップ＋コードの重ね掛け。
5. **リグ**: ヒューマノイド。ボーン名は次のいずれかの規約に統一:
   - Mixamo系: `mixamorig:Hips, Spine, Spine1, Spine2, Neck, Head,
     LeftShoulder, LeftArm, LeftForeArm, LeftHand,（Right同様）
     LeftUpLeg, LeftLeg, LeftFoot, LeftToeBase,（Right同様）`
   - または VRM / UniVRM のヒューマノイド名
   （どちらでもよいが、**全ボーン名の一覧を添付**すること）
6. **ポリゴン数**: 30,000三角形以下（スマホWebGL・60fps目標）。
7. **テクスチャ**: 2048px以下、合計3枚以内。PBRでなくてよい
   （ゲームはセルルック。ベースカラー＋シンプルな陰影で十分）。
8. **サイズ**: .glb 1ファイル 8MB以下
   （単一HTML配布のため base64 埋め込みする。16MB上限の半分まで）。
9. **グローブ**: 4オンスMMAオープンフィンガー。手ボーンの子として
   メッシュを分けておく（拳の回内をコードで回すため）。
10. **顔**: 表情モーフ（BlendShape）があれば使う。最低限:
    `blink`（まばたき）, `mouthOpen`（呼気）, `pain`（被弾）。
    名前一覧を添付。無くても組み込みは可能。

## あると良いもの（任意）

- 3体分の差分（アラタ/ゴウ/レン）: 同一リグ・同一ボーン名で
  メッシュとテクスチャだけ差し替え。体格差はコード側で対応可能なので
  1体でも成立する。
- 汗・ダメージ用の追加テクスチャ（頬の腫れなど）。

## 組み込み側（こちら）の予定

- three.js（cdnjs配信のUMDビルド）で WebGL レイヤーを追加し、
  既存の Canvas 2D エフェクト（集中線・汗・墨の一閃）を上に重ねる。
- クリップは AnimationMixer で再生するが、**再生時刻はコードが毎フレーム
  明示的に与える**（mixer.setTime 方式）。主観時間スローはこれで実現する。
  tell（予備動作）区間＝クリップ序盤、インパクトフレーム＝ex.impact に一致
  させる時間ワープを行う。
- その上に手続き層: 頭・視線の追従、被弾方向、選手ごとの姿勢オフセット、
  拳の回内。文献の実測値（肘角・運動連鎖順序）は検収基準として使う。
- 受け取り後、まず1体をゲーム内の全12状況で検証してから差し替える。

## v02 依頼事項（実機確認とアニメーション方針決定後・2026-08-31）

### アニメーションクリップ（最優先）
Mixamo（無料・要Adobeアカウント）から以下を取得して1つのGLBに同梱する。
ボーン名がMixamo互換なのでそのまま適用できるはず。

検索名 → クリップ名（この名前でエクスポート）:
- "Boxing Idle"（構えて揺れるもの）→ `idle_guard`
- "Jab" / "Punch"（前手の刺し）→ `jab`
- "Cross Punch"（後手ストレート）→ `cross`
- "Hook Punch" → `hook_lead`
- "Uppercut" → `uppercut_rear`
- "Roundhouse Kick" または "Low Kick" → `kick_low`
- "Takedown" 系 → `takedown`
- "Head Hit" / "Receive Punch" → `hit_head`
- "Knocked Out" → `ko`

ダウンロード設定: FBX Binary / **Without Skin** / 30fps / Keyframe Reduction: none / **In Place にチェック**（あるもの）

ゲーム側は実装済み: クリップがGLBに入っていれば自動でクリップ駆動へ
切り替わる（無ければ従来の手続き駆動）。インパクト時刻は手首の前方
到達最大で自動検出するので、フレーム表は「あれば尚良し」程度でよい。

### モデル修正
1. 眉・髪・瞳（テクスチャまたはメッシュ）。表情はゲームの「読み」の核。
2. ショーツのウェイト修正（膝曲げポーズで腿が突き抜ける）
3. 指スタブ一体型OFGグローブ（現在は素手の指を潰して収納している）
