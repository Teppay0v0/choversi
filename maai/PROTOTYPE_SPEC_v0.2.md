# MAAi -間合- プロトタイプ仕様書 v0.2

更新日: 2026-08-28  
ステータス: プレイテスト用仮仕様

## 1. コンセプト

相手の予備動作を読み取ることで主観時間の「間」へ入り、スローモーションの中で防御・回避・反撃を組み立てる、縦持ち一人称MMAゲーム。

本作では、目線、肩、腰、足音、呼吸から相手の攻撃を読む。読みが成立した瞬間、世界が遅くなり、プレイヤーは自分の腕・頭・身体を操作して攻防を選ぶ。入力決定後は通常速度へ戻り、結果が一気に決着する。

距離によって使用可能な技と相手の攻撃パターンも変化する。プレイヤーは攻撃に反応するだけでなく、距離を動かすことで次に起こり得る攻防を選択する。

### ブランドメッセージ

> 見えた瞬間、世界は遅くなる。  
> When you see it, time slows.

### 体験の柱

1. 相手の目線・肩・腰・呼吸から攻撃の起こりを読む
2. 読みに成功すると主観時間が遅くなり、攻防を視認して選べる
3. 自分の腕が指へ追従し、実際に守り、かわし、殴った感触を得る
4. 入力決定後に通常速度へ戻り、攻防が拍へ着地する
5. 遠距離・打撃距離・密着距離を奪い合う
6. 打撃とタックルの二択、フェイントを見抜く

## 2. プロトタイプの目的

第一段階では10秒前後の単一攻防、第二段階では60秒の試合で以下を検証する。

- 相手の予備動作を見て、攻撃方向を判断できる
- スローへの移行が「自分には見えた」という報酬に感じられる
- 長押しに合わせて自分の腕が上がり、ガードしている感覚がある
- スライドに合わせて頭・肩・カメラが動き、拳をかわした感覚がある
- タップ・スライド後に自分の拳が相手へ届き、接触を理解できる
- 通常速度→スロー→通常速度の変化が気持ちよい
- 攻撃スライドと回避スライドを誤認しにくい
- 距離を自分で支配している感覚がある
- 打撃とタックルを予備動作から判別できる
- 成功後に次の攻撃機会または距離的優位を獲得したことが理解できる

## 3. 対象環境

- 対象OS: iOS
- 基準端末: 縦持ちiPhone
- 基準アスペクト比: 9:19.5
- 操作: 左右の親指
- フレームレート目標: 60 fps
- 単一攻防試作: 8〜12秒
- 試合試作: 60秒、1ラウンド
- 基準テンポ: 100 BPM
- 1拍: 600 ms
- 1/2拍: 300 ms
- 推奨エンジン: Unity（技術検証後に最終確定）

Unityを推奨する理由は、iOS向け3D描画、タッチ入力、触覚、セルルック表現、将来のPC展開を同一プロジェクトで扱いやすいため。初期検証では実機iPhoneを必須とし、エディタ上のマウス操作だけで入力感を判断しない。

PC版を想定し、ゲーム内部ではタッチ座標ではなく共通アクションイベントとして管理する。

```text
LEFT_PRESS / LEFT_RELEASE
RIGHT_PRESS / RIGHT_RELEASE
LEFT_SWIPE_IN / RIGHT_SWIPE_IN
LEFT_SWIPE_OUT / RIGHT_SWIPE_OUT
LEFT_SWIPE_UP / RIGHT_SWIPE_UP
DUAL_SWIPE_UP / DUAL_SWIPE_DOWN / DUAL_SWIPE_IN
```

## 4. 画面構成

- 上部15%: HP、スタミナ、残り時間
- 中央70%: 相手、金網、距離表現、予備動作
- 下部15%: 難易度に応じた操作補助と距離表示
- 入力領域: 画面全体を左右50%ずつに分割
- 左右入力領域の境界には、常時表示する線を置かない
- 一人称視点では、自分の左右の腕を前腕からグローブまで常時表示する
- ガード時は前腕とグローブが画面中央へ入り、視界を意図的に狭める
- 攻撃時は腕の軌道を入力ジェスチャーと一致させる

初心者モードのみ、タッチ時に左右の入力領域を薄く表示する。

### 一人称の腕表示

- ニュートラル時: グローブと前腕の一部を画面下左右に表示
- ガード時: 肘より先を表示し、左右どちらを守っているか明確にする
- ストレート時: 肩そのものは見せず、上腕の一部まで画面へ入れる
- フック時: 前腕の横軌道が読める範囲まで表示する
- 被弾時: 腕とカメラを別々に揺らし、入力位置を見失わせない
- 腕による相手の予備動作の隠れ方も、ガードのリスクとして利用する

## 4.1 ビジュアル方針

表現は写実ではなく、洗練されたセルルックを採用する。目標はコミカルなアニメ調ではなく、ファッション、格闘技ポスター、ミュージックビデオを掛け合わせたスタイリッシュな方向性とする。

### 表現原則

- キャラクター: 面を整理した造形、抑制した輪郭線、鋭いシルエット
- 顔: 彫刻的セルルックを正式採用。頬骨、眉、鼻、顎を少数の大きな面で構成する
- 目線: 常に判読可能にし、攻撃方向、フェイント、感情を伝えるゲーム情報として扱う
- 顔の上半分を隠す墨影表現は不採用。墨は背景、軌道、判定演出に限定する
- 色: 1試合につき基調色2色＋アクセント1色を基本とする
- 光: リングライト、観客席、金網の影を大胆にデザインする
- 打撃: 常時エフェクトを出さず、PERFECT時だけ色・残像・コマ落としを強調する
- UI: スポーツ中継より、レコードジャケットや高級ファッション誌に近い構成
- 汗・流血: 写実的な質感より、粒子・線・色面として抽象化する
- 背景: 情報量を抑え、相手の肩・腰・脚の予備動作を最優先で読めるようにする

セルルックの美しさとゲーム上の視認性を両立するため、攻撃予備動作に使う身体部位と背景が同じ明度にならないよう、戦闘中のカラー設計を制約する。

## 4.2 キャラクターデザイン設計

キャラクターは顔だけを先に作らず、見た目、戦術、リズム、話し方を一つの人物設計として作る。

### キャラクター定義項目

| 項目 | 定義内容 |
|---|---|
| シルエット | 身長、体格、肩幅、リーチ、重心、構え |
| 顔の面構成 | 眉骨、頬骨、鼻、顎、目の形、左右差 |
| 目線 | 通常、攻撃前、フェイント、被弾、劣勢時の変化 |
| 戦闘スタイル | 打撃、レスリング、寝技、得意距離 |
| 基本リズム | 等間隔、溜め、裏拍、連打、変拍子的な崩し |
| 身体の癖 | 呼吸、瞬き、肩、足踏み、ガード位置 |
| 人格 | 価値観、弱点、怒る条件、敬意を示す条件 |
| 話し方 | 語彙、速度、声量、沈黙の長さ、視線の置き方 |
| 墨の筆致 | 攻撃時に現れる線の太さ、かすれ、形 |
| 色 | 選手固有のアクセント色とグローブ・ショーツ |
| 因縁 | 主人公との関係、試合をする理由、再戦時の変化 |

### 顔の制作ルール

- 目、眉、鼻、口を線で描き込みすぎず、明暗の面で認識させる
- 通常距離、接近、被弾の3距離で破綻しないことを確認する
- 左右・上下の視線が一人称カメラから明確に読めることを必須とする
- 攻撃前の視線はヒントになるが、必ず攻撃方向と一致させずフェイントを可能にする
- 表情シェイプは「通常・集中・挑発・疲労・動揺・被弾」の6種類から開始する
- 顔の魅力を髪型や影だけに依存させない

### 初期キャラクター構成

プロトタイプでは量産せず、以下の3名に集中する。

1. 主人公: 基準となるオールラウンダー。試合中は腕のみ、会話シーンで顔を表示
2. 最初のライバル: 打撃型。目線と肩で攻撃を読みやすく、フェイントを一つ持つ
3. 次の強敵: レスリング型。目線を上に残したまま腰を落とし、打撃とタックルを混ぜる

各キャラクターは正面顔だけで承認せず、フェイスオフ、通常構え、攻撃予備動作、疲労状態の4場面を一組として評価する。

## 5. 距離システム

距離は内部的にも3段階で管理する。

| ID | 距離 | 主な行動 |
|---|---|---|
| 0 | 遠距離 | ロー、ミドル、前蹴り、前進、タックル警戒 |
| 1 | 打撃距離 | ジャブ、ストレート、フック、アッパー、タックル |
| 2 | 密着距離 | ショート打撃、肘、膝、組み |

### 距離変更

- 両指上スライド: 1段階接近
- 両指下スライド: 1段階後退
- 強打を受ける: 30%の確率で1段階後退
- PERFECTカウンターを受ける: 必ず1段階後退
- タックル成功: グラウンド状態へ遷移（初期版では成功演出後に終了）
- タックルを部分防御: 密着距離へ遷移

### 移動時間

- 通常ステップ: 300 ms
- PERFECTステップ: 240 ms
- ステップ中に被弾: ダメージ1.25倍
- ステップのスタミナ消費: 4

### 金網圧力

プレイヤーと相手はそれぞれ0〜2の「金網圧力」を持つ。

- 遠距離でさらに後退: 金網圧力+1
- 金網圧力2: 金網際状態
- 金網際では後退不可
- PERFECT回避後の回り込み: 金網圧力-1
- PERFECTカウンター成功: 自分の金網圧力-1、相手の金網圧力+1

## 6. 基本操作

| 入力 | 遠距離 | 打撃距離 | 密着距離 |
|---|---|---|---|
| 左タップ | 左前蹴り | 左ジャブ | 左ショートフック |
| 右タップ | 右ローキック | 右ストレート | 右肘 |
| 内側スライド | ミドルキック | フック | 肘・膝 |
| 上スライド | ハイキック | アッパー | 膝 |
| 外側スライド | 回り込み | 回り込み／スリップ | 組みから横へ動く |
| 長押し | 左右ガード／キックチェック | 左右ガード | フレーム・首防御 |
| ガード後に離す | クイックカウンター | クイックカウンター | 押し返し |
| 両指上スライド | 前進 | 前進 | 押し込み |
| 両指下スライド | 後退 | 後退／スウェー | 組みを離す試行 |
| 両指中央スライド | タックルフェイント | タックル | ボディロック |
| 両指長押し | 低い構え | スプロール | 組み防御 |

プロトタイプでは密着距離の自由攻防は実装せず、到達後に短い結果演出を再生して打撃距離へ戻す。

## 7. ジェスチャー認識

画面サイズに依存しないよう、距離はdp相当または画面短辺比で判定する。

### 初期閾値

- タップ最大時間: 180 ms
- タップ最大移動量: 画面短辺の3%
- スライド成立距離: 画面短辺の7%
- 長押し成立時間: 220 ms
- 両指入力の同時許容差: 140 ms
- 方向判定: 主要方向から±30度
- ガード中の微小移動無視: 画面短辺の5%まで

### 判定優先順位

1. 2本目の指が140 ms以内に入った場合は両指入力候補
2. スライド成立距離を超えたら方向ジェスチャー
3. 220 ms静止したら長押し
4. 180 ms以内に離し、移動量が閾値未満ならタップ
5. 上記を満たさない場合は無効入力

長さや速度だけで技を分けない。開始した左右領域、方向、片指／両指で区別する。

## 8. 文脈型回避

外側スライドは常に「その方向へ身体を動かす」という意図として扱う。

- 攻撃判定が接近中: スリップ
- 攻撃がない: 回り込み
- スリップ成功後も移動可能: 角度取得
- 金網際: 中央への脱出
- タックル接近中: タックルの正面線から外れる

プレイヤーの意図と演出の不一致を避けるため、スリップ後は可能な限り同方向への回り込みまで連続再生する。

### 回避相性

| 相手の技 | 安全な対応 | 危険な対応 |
|---|---|---|
| ジャブ | 左右スリップ、スウェー | 無防備な前進 |
| ストレート | パンチの外側へのスリップ | パンチ側へ入る |
| フック | スウェー、ガード | フック軌道側へのスリップ |
| アッパー | 左右スリップ、後退 | 前進、低い姿勢 |
| キック | ガード、後退 | 頭だけのスリップ |
| タックル | スプロール、横回避 | 直線後退のみ |

## 9. リズム判定

リズムはノーツを処理するためではなく、相手の身体が攻撃を開始する規則性として使用する。足音、呼吸、重心移動、打撃音が拍を構成する。

入力時刻と技のインパクト時刻との差で判定する。

| 判定 | 時間差 | 基本効果 |
|---|---:|---|
| PERFECT | ±70 ms | 完全成功＋有利状態 |
| GOOD | ±150 ms | 通常成功 |
| EARLY | -250〜-151 ms | 成功するがスタミナ消費増加 |
| LATE | +151〜+250 ms | 部分成功、チップダメージ |
| MISS | 上記以外 | 被弾、空振り、または移動失敗 |

### 有利状態

PERFECT防御・回避後、600 msのカウンター受付時間を与える。

- 受付中の攻撃: ダメージ1.5倍
- PERFECTカウンター: ダメージ1.8倍、相手を1段階後退
- 受付時間を使わない: スタミナ5回復

端末の音声・描画遅延に対応するため、設定画面に±200 msのタイミング補正を用意する。

## 9.1 主観時間システム

主観時間は演出だけではなく、防御・回避・反撃を組み立てる操作空間である。

### 基本フロー

```text
通常速度で観察
    ↓
相手の予備動作を認識
    ↓
主観時間へ移行
    ↓
ガード／スリップ／後退／迎撃を選択
    ↓
自分の腕・頭・身体が入力へ追従
    ↓
行動を確定
    ↓
通常速度へ復帰
    ↓
接触、回避、距離変化が一気に解決
```

### 初期時間設定

| 状態 | Time Scale | 実時間の目安 | 目的 |
|---|---:|---:|---|
| 観察 | 1.0 | 可変 | 呼吸・足音・フェイントを読む |
| 読み成立 | 0.35へ遷移 | 120 ms | 世界が開ける感覚を作る |
| 攻防選択 | 0.25 | 最大1.2秒 | 腕・頭・距離を操作する |
| 行動確定 | 0.25→1.0 | 100 ms | 拍へ戻る加速感を作る |
| 接触 | 0.0〜0.05 | 40〜70 ms | 衝撃と接触位置を認識させる |
| 解決 | 1.0 | 300〜600 ms | 後退、崩れ、距離変化を見せる |

時間減速中も入力処理、UI、触覚は実時間で動作させる。アニメーション、物理、敵の攻撃進行のみ主観時間の影響を受ける。

### 発動条件

単一攻防プロトタイプでは、予備動作開始後に自動発動する。面白さが確認できた後、以下へ段階的に移行する。

- 正しい身体部位を見ていた／正しい初動入力をした場合に発動
- 早く予備動作を見抜くほど、拳が遠い段階からスローになる
- フェイントに反応すると主観時間を消費し、本命への受付が短くなる
- 連続して正しく読むと、次の攻撃がより早く見える
- 数値成長だけでなく、プレイヤー自身が予備動作を学習する構造にする

### 「間」リソース案

完成版では主観時間の深さ・長さを「間」で管理する候補を残す。

- 正しい読み、PERFECT回避、カウンター成功で増加
- 空振り、過剰反応、フェイントへの反応で減少
- 間が多いほど減速開始が早く、選択時間が長い
- 間が少ないほど減速が浅く、通常の反射能力が要求される

初期プロトタイプではゲージ化せず、毎回同じ減速を提供する。

### 音響

- 主観時間へ入る瞬間、観客と環境音をローパス処理する
- 相手の呼吸と衣擦れは残し、攻撃方向の情報を失わせない
- 心拍は実時間に近い速度で鳴らし、主観時間の基準にする
- 行動確定時、環境音が急速に通常速度へ戻る
- 打撃音は通常速度へ復帰した拍へ着地させる

## 11. タックル

### 攻撃入力

両指を画面外側から中央へ同時スライドする。

- 遠距離: 失敗またはフェイント扱い
- 打撃距離: タックル
- 密着距離: ボディロック

### 防御選択

| 入力 | 行動 | リスク／リターン |
|---|---|---|
| 両指長押し | スプロール | 最も安全。早すぎると頭部ガードが下がる |
| 外側スライド | 横回避 | 成功時は角度取得。遅いと片脚を取られる |
| 上スライド | 膝・アッパー迎撃 | PERFECTなら大ダメージ。失敗時はテイクダウン |

### 結果

- PERFECTスプロール: タックル阻止、相手スタミナ-15、有利状態
- GOODスプロール: タックル阻止、密着距離へ
- EARLYスプロール: 阻止するがスタミナ-12
- LATEスプロール: 金網際の密着距離へ
- MISS: テイクダウン、プロトタイプ上は敗北演出

### フェイント

プロトタイプでは敵のみ使用する。

- 腰を落とす予備動作を150 msだけ見せる
- 本タックルは腰を落としてから450〜600 ms後に接触
- フェイント後は右ストレートまたは左フックへ派生
- 早すぎるスプロール中は頭部被ダメージ1.3倍

## 12. ノーツ・視認補助

| 難易度 | 表示 | 判定幅補正 |
|---|---|---:|
| BEGINNER | 操作アイコン、左右方向、収束リング | 1.5倍 |
| NORMAL | 方向と収束リング | 1.0倍 |
| HARD | 攻撃部位付近に短い予告 | 0.8倍 |
| REAL | UIノーツなし。身体と音のみ | 0.8倍 |

初回プロトタイプはBEGINNERとNORMALのみ実装する。

主観時間導入後は、矢印や収束リングよりも自分の腕、相手の拳、接触予測位置を優先する。BEGINNERのみ、正しい移動方向と操作する腕を短時間表示する。

## 13. テストシーケンス

### 第1段階: 10秒の単一攻防

```text
相手が通常速度で呼吸
→ 踏み込み
→ 目線と肩が動く
→ 主観時間が0.25倍へ低下
→ プレイヤーがガードまたはスリップ
→ カウンターを選択
→ 通常速度へ復帰
→ 拳が接触
→ 相手が一歩後退
```

合格条件は「自分の腕で守り、自分の拳で当てた」と感じること。HP、勝敗、スタミナ、複数技はこの段階では評価しない。

### 第2段階: 60秒の攻防

基準テンポ100 BPM。以下の拍番号は1拍600 ms。

| 拍 | 距離 | 相手の行動 | 想定される対応 | 検証対象 |
|---:|---|---|---|---|
| 1〜4 | 遠距離 | 構え・足踏み | なし | テンポ認識 |
| 5 | 遠距離 | 前進予告 | ローキック | 牽制 |
| 7 | 遠距離 | 再前進 | 両指上で迎える／維持 | 距離変更 |
| 9 | 打撃 | 左ジャブ | 外側スライドまたはガード | 基本防御 |
| 11 | 打撃 | 右ストレート | 外側スライド | スリップ |
| 12 | 打撃 | 隙 | 左フック | カウンター |
| 16 | 打撃 | 左フック | ガードまたは後退 | 技の見分け |
| 20 | 打撃 | タックルフェイント | 待つ | フェイント判断 |
| 21 | 打撃 | 右ストレート | 回避／ガード | 早い防御への罰 |
| 26 | 打撃 | 本タックル | 両指長押し | スプロール |
| 32 | 密着 | 押し込み演出 | 外側スライド | 金網脱出 |
| 38 | 打撃 | ジャブ→ストレート | 防御→カウンター | 連続入力 |
| 44 | 打撃 | 後退 | 両指上スライド | 追い足 |
| 48 | 遠距離 | ミドルキック | ガード／後退 | キック防御 |
| 54 | 打撃 | タックル | スプロール／迎撃 | 選択防御 |
| 58〜60 | 可変 | ダウンまたは終了演出 | なし | 結果理解 |

残りの拍には移動、呼吸、フェイント、プレイヤーの自由攻撃を配置する。毎拍入力を要求しない。

## 14. フィードバック

### 視覚

- 読み成立: 背景と敵の運動が滑らかに減速し、自分の腕は即時反応を維持
- ガード: 自分の前腕と相手の拳が実際に接触する
- スリップ: 相手の拳が顔の横を通過し、開いた顎・脇が見える
- カウンター: 自分の拳が画面下から接触点まで連続して移動する
- PERFECT: 接触点の短い白フラッシュ、墨の一閃、40〜70 msの停止
- GOOD: 小さな接触エフェクト
- MISS: 色収差、被弾方向へのカメラ揺れ
- 距離変更: 相手のサイズと背景パララックスで表現
- 有利状態: 相手の姿勢崩れを優先し、UI発光は補助に留める

### 音

- 楽曲を主役にせず、足音、呼吸、観客、金網、打撃音でリズムを構成する
- 相手の踏み込みを拍の基準音にする
- パンチ、ガード、回避、足音を見えない打楽器パートとして構成する
- タックル予告は低域の足音と短い呼吸音
- PERFECT時のみ打撃音へ追加の低音を重ねる
- 観客の手拍子や歓声は、試合の優勢・劣勢に合わせてリズム層として増減する
- 選手の疲労に応じて呼吸音を強くし、テンポ感とスタミナ情報を兼ねる
- BGMを使用する場合も旋律を前面に出さず、環境音と一体化した低いパルスに留める

### リズム音響レイヤー

| レイヤー | 役割 |
|---|---|
| 足音 | 基本拍、前進・後退・タックルの予告 |
| 呼吸 | 裏拍、疲労、攻撃前の吸気 |
| グローブ・打撃音 | プレイヤー入力への即時フィードバック |
| 金網・床 | 距離、位置、押し込み状態の情報 |
| 観客 | 緊張度、連続成功、試合展開の盛り上がり |
| 低域パルス | 初心者向けの補助拍。高難易度では弱める |

### 触覚

- GOOD: 短い弱振動
- PERFECT: 短い強振動
- ガード: 2連の弱振動
- 被弾: 長めの強振動

## 15. 勝敗

プロトタイプでは以下のいずれかで終了する。

- 相手HPが0: KO勝利
- プレイヤーHPが0: KO敗北
- タックルをMISS: テイクダウン敗北演出
- タックル迎撃PERFECT: 特殊勝利演出
- 60秒終了: 残HP、距離支配、PERFECT数で判定

判定スコア:

```text
残HP差 × 10
+ PERFECT数 × 100
+ 有利距離を維持した秒数 × 20
+ 相手を金網際に置いた秒数 × 15
- 自分が金網際にいた秒数 × 15
```

## 16. プレイテスト計測

最低5人、可能ならMMA経験者と未経験者を分けて記録する。

- 初回説明にかかった時間
- 各ジェスチャーの認識成功率
- 意図した技と実際に出た技の一致率
- PERFECT／GOOD／MISS率
- 攻撃と回避の誤操作数
- 両指操作の失敗数
- 60秒間の距離変更回数
- 金網際からの脱出成功率
- タックルと打撃の見分け成功率
- 「距離を自分で管理した」と感じたか（5段階）
- 「音と攻防が合って気持ちよかったか」（5段階）

### 初回合格基準

- 単指スライド認識成功率: 90%以上

## 16.1 試合前プロモーションとトラッシュトーク

試合前の言葉を単なるムービーではなく、対戦相手の感情、初動パターン、観客リズム、興行評価へ接続する。

### 試合前の流れ

1. 対戦カード発表
2. 短いインタビューまたは記者会見
3. 計量・フェイスオフ
4. バックステージ
5. 入場・ケージ内対峙
6. 試合
7. 試合後コメント

全工程を毎試合強制しない。重要試合だけ長く見せ、通常試合は15〜30秒へ短縮またはスキップ可能にする。

### プレイヤーの発言姿勢

| 選択 | 意図 | 試合への影響 |
|---|---|---|
| 挑発 | 相手を熱くする | 相手の初動が攻撃的かつ読みやすくなるが、プレッシャーが強い |
| 分析 | 弱点を指摘する | 特定パターンの予備動作情報を得るが、興行の盛り上がりは小さい |
| 敬意 | 冷静に向き合う | 自分の集中を維持するが、相手も冷静でパターンが多彩になる |
| 沈黙 | 言葉を使わず圧をかける | 効果が相手の性格によって変化する |

善悪の正解にはしない。挑発は悪、敬意は善という設計ではなく、相手の性格を読んで試合展開を選ぶ戦略とする。

### 管理値

- HEAT: 観客と因縁の盛り上がり。報酬、演出、歓声レイヤーに影響
- COMPOSURE: 自分と相手の冷静さ。攻撃パターンの安定性に影響
- INTEL: 相手の技・予備動作に関する情報。試合中の補助表示に影響
- RIVALRY: 過去の発言と試合結果を記録する長期的な因縁

### 試合への接続例

- 相手のタックル技術を挑発する → 相手が序盤にタックルを証明しようとする
- 相手のスタミナを指摘する → 相手が前半から飛ばす／逆に慎重になる
- KO宣言をする → 成功時のHEAT増加、判定勝ちでは評価が少し下がる
- 沈黙してフェイスオフを続ける → 観客音が消え、試合開始の足音が強調される
- 相手が発言を撤回しない → 再戦時に専用の短い攻撃パターンが追加される

### キャラクター別反応

- 激情型: 挑発に反応し、強いが単調な前進パターンが増える
- 冷静型: 挑発を逆利用し、フェイント率が上がる
- 自信家: 観客のHEATが高いほど大技を狙う
- 職人型: 言葉には反応せず、分析されると戦術を変更する
- エンターテイナー型: 会見では激しく、試合では冷静という二面性を持つ

### 表現方針

- 台詞だけでなく、目線、間、マイクを持つ手、立ち上がる速度で感情を見せる
- 墨の余白と無音を使い、叫び続ける演出にしない
- 発言の最後の呼吸や机を叩く音を、そのまま対戦テーマのリズムへ接続する
- 差別表現、実在人物への中傷、現実の犯罪を想起させる過度な脅迫は扱わない
- 実在団体や実在選手の発言・容姿・因縁をそのまま再現しない

## 17.1 相手AI・攻撃パターン

相手の攻撃は60秒間の完全固定譜面ではなく、短いパターンを状況に応じて組み合わせる。

### パターンの基本単位

- 長さ: 2〜8拍
- 開始条件: 距離、金網圧力、スタミナ、直前のプレイヤー行動
- 内容: 予備動作、攻撃、移動、フェイント、隙
- 終了結果: 距離維持、接近、後退、密着、有利・不利

### 初期パターン例

| ID | 条件 | 内容 |
|---|---|---|
| P01 | 打撃距離 | ジャブ → 休み → ストレート |
| P02 | 打撃距離 | ジャブ → ジャブ → 後退 |
| P03 | 打撃距離 | タックルフェイント → 右ストレート |
| P04 | 打撃距離 | 本タックル |
| P05 | 遠距離 | 前進 → ミドルキック |
| P06 | 遠距離 | 前進 → 打撃距離へ移行 |
| P07 | 金網際 | フック → ボディ → タックル |
| P08 | 被カウンター後 | ガード → 後退 |

完全なランダム抽選にはしない。次の攻撃が理不尽にならないよう、各パターンには接続可能な次パターンを定義する。同じパターンは原則3回連続で使用しない。

BEGINNERではパターン順をほぼ固定し、NORMAL以上では条件付き抽選にする。同じ相手には固有のリズム傾向を持たせ、繰り返し戦うことで攻略可能にする。

## 18. 実装優先順位

1. 相手の右ストレートと、目線・肩・腰・足の予備動作
2. 1.0→0.25→1.0の主観時間遷移
3. 長押しに追従する左右の腕とガード接触
4. 外側スライドに追従する頭・肩・カメラ移動
5. タップ／スライドに追従して相手へ届く自分の拳
6. 接触位置、ヒットストップ、墨、音、振動
7. 左ジャブと右ストレートの二択
8. 3段階の距離遷移
9. フック、キック、タックル、スプロール
10. 60秒シーケンスと計測ログ
